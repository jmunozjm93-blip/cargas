Adjunta el Excel de cargas (el que trae la hoja Datos con una fila por OC · modelo · tienda). La app lo valida, lo convierte y lo sube a GitHub; el dashboard muestra las OC nuevas como pendientes para cada supervisora. Si una OC ya estaba cargada, se reemplaza. También acepta Excel_Macro.xlsx para actualizar las fotos de los modelos.

¿Cómo creo el token?
  1. Entra a github.com/settings/personal-access-tokens/new
  2. Token name: cargar oc · Expiration: 1 año (o "No expiration")
  3. Repository access: "Only select repositories" → elige cargas
  4. Permissions → Repository permissions → Contents: Read and write (nada más)
  5. Generate token → cópialo y pégalo arriba. Queda guardado solo en este navegador.

Este token se guarda aparte del de Levantamiento: cada app usa el suyo.
